# Security Policy

## Supported Versions

Only the latest published version of each `@cachehit` extension receives security fixes. Update with
`swamp extension pull <name>` before reporting.

## Reporting a Vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/zWaR/swamp-extensions/security/advisories/new). Do not
open a public issue.

Include the affected extension and version, steps to reproduce, and the impact you expect. You should get a reply
within 7 days. Fixes ship as a new extension version, and the advisory is published once the fix is available.
